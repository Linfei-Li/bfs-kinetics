# Code and data availability

The following statements are the authoritative versions used in the
manuscript. The scripts released with the paper are system-independent
analysis routines; proprietary data and the trained potential are not
released.

## Code availability

The analysis scripts used for coordination-shell traversal, per-cluster event
statistics and zoned kinetic fitting are system-independent, general-purpose
routines. They will be released on GitHub and archived on Zenodo after
acceptance (links and DOI to be added). The scripts do not include the
trained Deep Potential.

## Data availability

The aggregate statistics and complete figures supporting the conclusions of
this study are provided in the main text and the Supplementary Information.
Owing to a legally binding commercial agreement, the raw DPMD trajectories,
DFT reference data and the trained potential are not publicly available.
